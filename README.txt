KARIKARIA WEBSITE

File:
- index.html  : struktur dan konten beranda website
- galeri.html : halaman galeri foto karya dengan fitur Load More
- style.css   : desain, gradasi warna, animasi, dan responsive layout
- script.js   : menu mobile, animasi scroll, dan fitur Load More foto galeri
- assets/     : gambar karya karikatur dan logo resmi Karikaria

PENGATURAN WAJIB SEBELUM DIPUBLIKASIKAN
1. Buka index.html dengan editor kode.
2. Ganti semua teks 628xxxxxxxxxx dengan nomor WhatsApp bisnis berformat internasional tanpa tanda + atau spasi.
   Contoh format: 6281234567890
3. Ganti https://shopee.co.id/ dengan URL toko Shopee Karikaria.
4. Ganti https://www.lazada.co.id/ dengan URL toko Lazada Karikaria.
5. Simpan logo resmi dengan nama logo.png di folder yang sama dengan index.html.
6. Ganti tiga ilustrasi contoh di bagian Karya dengan gambar portofolio asli jika sudah tersedia.

CARA MENJALANKAN
Klik dua kali index.html untuk melihat website di browser. Untuk mengunggah ke hosting, unggah keempat file (termasuk logo.png) dalam satu folder.
